# 🎮 Tic Tac Toe – Python Game

A classic Tic Tac Toe game developed using Python and Pygame.

## ✨ Features
- Interactive 3×3 game board
- Two-player gameplay (X and O)
- Mouse-based controls
- Automatic turn switching
- Win and draw detection
- Game restart functionality

## 🛠️ Technologies Used
- Python
- Pygame

## 🚀 Installation

Install Python, then install Pygame:

```bash
pip install pygame
```

## ▶️ Run the Game

```bash
python tictactoe.py
```

## 🎯 How to Play
1. Player X starts the game.
2. Player O takes the next turn.
3. Click an empty cell to place your mark.
4. Align three marks horizontally, vertically, or diagonally to win.
5. The game detects a draw when all cells are filled without a winner.
